# Contributing to FeishuNext

本仓库是 **FeishuNext**（[askofcc/FeishuNext](https://github.com/askofcc/FeishuNext)）。

## 请注意

- **不要**向 [notionnext-org/NotionNext](https://github.com/notionnext-org/NotionNext) 提本仓库的飞书相关 PR（除非你明确在贡献上游本身）。
- 飞书数据与适配改动：优先 `lib/feishu/`、`lib/site/adapters/feishu/`、`docs/feishu/`。
- 主题/壳改动：尽量保持与上游 NotionNext 可合并；正文继续走 `NotionPage` → Feishu 渲染。

## 开发

见根目录 [README.md](./README.md) 与 [docs/feishu/THEME_DATA_CONTRACT.md](./docs/feishu/THEME_DATA_CONTRACT.md)。

## 上游文档

仓库内部分 `CONTRIBUTING.zh-CN.md` / `GOVERNANCE*` 等仍是 NotionNext 原文，**不适用于本产品的贡献流程**；仅作历史参考。
